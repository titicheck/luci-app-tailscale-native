# v1.0.0 Release Notes

First stable release of Tailscale Native LuCI.

v1.0.0 promotes the accepted v1.0.0-rc1-r2 package without adding new control capabilities. The release freezes the seven-page control surface, official-Core authority model, LocalAPI browser login, partial preference writes, update controls, role guards, minimal fw4 glue ownership, and package lifecycle safety policy.

Validated on iStoreOS 24.10.8 with official Tailscale runtime 1.102.3.
